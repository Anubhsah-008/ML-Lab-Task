# Machine Learning Lab Tasks

This repository contains Machine Learning lab programs implemented using Python. It includes classification techniques using Random Forest and Artificial Neural Networks (ANN) with the Backpropagation algorithm.

## Project Structure

```text
ML-Lab-Task/
│
├── Random Forest/
│   ├── randomforest.ipynb
│   └── data.csv
│
├── Back Propagation/
│   ├── backpropogation.ipynb
│   └── Iris.csv
│
└── README.md
```

## Programs Included

### 1. Random Forest Classification

- **Algorithm:** Random Forest Classification
- **Dataset:** Breast Cancer Wisconsin Dataset (`data.csv`)
- **Libraries:** NumPy, Pandas, Matplotlib, Scikit-learn
- **Operations:**
  - Data preprocessing
  - Splitting training and testing datasets
  - Feature scaling
  - Training the Random Forest classifier
  - Making predictions
  - Confusion Matrix
  - Accuracy calculation

### 2. Artificial Neural Network (Backpropagation)

- **Algorithm:** Artificial Neural Network using Backpropagation
- **Dataset:** Iris Dataset (`Iris.csv`)
- **Libraries:** NumPy, Pandas, TensorFlow, Scikit-learn
- **Operations:**
  - Data preprocessing
  - Label Encoding
  - One-Hot Encoding
  - Splitting training and testing datasets
  - Feature scaling
  - Building and training the ANN
  - Making predictions
  - Confusion Matrix
  - Accuracy calculation

**ANN Test Accuracy:** 76.67% (observed execution)

## Installation

Install the required libraries using pip:

```bash
pip install numpy pandas matplotlib scikit-learn tensorflow
```

## How to Run

1. Clone this repository:

```bash
git clone https://github.com/Anubhsah-008/ML-Lab-Task.git
```

2. Open the project folder:

```bash
cd ML-Lab-Task
```

3. Launch Jupyter Notebook:

```bash
jupyter notebook
```

4. Open the respective `.ipynb` files.
5. Run all cells to execute the programs.

## Results

Both programs demonstrate classification techniques and model evaluation using test datasets, predictions, confusion matrices and accuracy scores.
